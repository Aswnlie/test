РОЛЬ 2 — Nurym Zhumabayev

Коротко о работе
Браузер открывает главную. JavaScript вызывает GET /api/movies. Oak получает фильмы из MySQL через Drizzle и возвращает JSON. JavaScript создает карточки из HTML template и вставляет названия через textContent, чтобы они не выполнялись как HTML-код.

Главные файлы
views/home.html — заголовок, список и шаблон одной карточки.
views/partials/header.html — ссылки Home, Log in, Register или аккаунт и выход.
views/layouts/main.html — общая HTML-страница и подключение CSS/JS.
public/css/style.css — один простой файл стилей для всех страниц приложения.
public/js/home.js — две функции: loadMovies и deleteMovie.
movies/home.ts — главная и два API-маршрута.
movies/catalogue.ts — чтение и удаление из MySQL.
docs/role-2.html — sitemap, сценарии и storyboard.

Простой API
GET /api/movies возвращает { movies, isAdmin, csrf }.
POST /api/movies/:id/delete принимает поле csrf в URL-encoded теле. JavaScript создает его через new URLSearchParams({ csrf }). Ответ — JSON с message, ошибка — JSON с error.
Сессионная cookie отправляется автоматически, потому что сайт и API находятся на одном адресе.

Даты
LEFT JOIN оставляет в списке фильмы без отзывов. MAX берет дату последнего отзыва. Если ее нет, используется дата добавления фильма. DATE_FORMAT задает YYYY-MM-DD. Поиск и блоки популярных/новых фильмов убраны как необязательные.

Удаление
ADMIN_USER_IDS в .env содержит ID администраторов через запятую. По умолчанию список пуст. ID нужно взять из существующей таблицы users. Сервер проверяет сессию, права, CSRF и ID фильма. Отзывы удаляются внешним ключом ON DELETE CASCADE. Кнопка скрыта у обычных пользователей, но основная защита находится на сервере.

Запуск
Скопировать .env.example в .env и указать свою MySQL. Затем deno install, deno task db:migrate, deno task db:seed-users, deno task start. Сайт: http://localhost:8000/. API: http://localhost:8000/api/movies.
Шаблоны .html обрабатывает Handlebars на сервере. Двойной клик по файлу их не запускает. Главной нужен JavaScript. При ошибке загрузки появится сообщение и кнопка Try again.

Что остается по брифу
