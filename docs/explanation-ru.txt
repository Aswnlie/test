РОЛЬ 2 — Nurym Zhumabayev

Структура по требованиям
Deno + Oak — сервер, MySQL + Drizzle — база, Handlebars — HTML-шаблоны .hbs.
Фронтенд: HTML, общий CSS и небольшой обычный JavaScript. TypeScript сохранен на сервере для совместимости с исходным репозиторием команды.

Как работает главная
1. Браузер запрашивает GET /.
2. movies/home.ts вызывает store.list() — чтение фильмов.
3. movies/catalogue.ts читает таблицы movies и reviews через существующий db-клиент.
4. cardData выбирает дату и безопасный путь к постеру.
5. render("home", данные) передает список в views/home.hbs.
6. {{#each movies}} повторяет карточку. {{#if @root.isAdmin}} показывает форму удаления только администратору.
7. views/render.ts помещает готовую страницу в layouts/main.hbs с общей шапкой partials/header.hbs.
Браузер получает готовый HTML. Отдельного JSON API для списка больше нет.

Файлы, которые нужно понимать
views/home.hbs — карточки: название, год, постер, дата, Details, Delete.
views/partials/header.hbs — навигация и форма выхода.
views/layouts/main.hbs — head, подключение CSS/JS, main и footer.
public/css/style.css — общий простой CSS и мобильная сетка.
public/js/home.js — подтверждение удаления и замена отсутствующей картинки.
movies/home.ts — подготовка данных и два маршрута.
movies/catalogue.ts — запросы к базе данных.
views/render.ts — загрузка и сборка шаблонов.

Почему дата правильная
LEFT JOIN оставляет фильмы без отзывов. MAX выбирает дату последнего отзыва. Если отзывов нет, lastReviewDate равна null, поэтому ?? берет createdDate. DATE_FORMAT задает YYYY-MM-DD. Даты в проекте хранятся в UTC.

Удаление
POST /movies/:id/delete принимает обычную HTML-форму с CSRF-токеном. Сервер проверяет сессию, ID администратора, токен и ID фильма. Затем удаляет запись и отвечает 303 с переходом на главную. ON DELETE CASCADE в БД удаляет отзывы этого фильма.
ADMIN_USER_IDS в .env — список ID существующих администраторов через запятую. Пустой список запрещает удаление всем. ID нельзя получить из пользовательской формы.
Без JavaScript список и форма работают; окно подтверждения появляется только с включенным JavaScript.

Безопасный вывод
{{title}} экранирует HTML. Нельзя менять его на {{{title}}}: тройные скобки выводят сырой HTML. Тройные скобки для body в layout нужны только для готового HTML из собственных шаблонов.

Проверка и запуск
Скопировать .env.example в .env и заполнить свою MySQL. Выполнить deno install, deno task db:migrate, deno task db:seed-users, deno task start. Открыть http://localhost:8000/.
Тест tests/home_test.ts проверяет серверный HTML, даты, экранирование, пустой список и защиту удаления без настоящей БД. Полную работу MySQL нужно проверять отдельно.

Что относится к остальной команде
Детали /movie/:id, добавление /movies/add, отзывы и сиды фильмов еще отсутствуют в этой ветке. Их делают другие участники. Все задание также требует реальные опросы, персоны, скетчи, две версии прототипов и пользовательское тестирование. Автотесты не заменяют UX-тесты.
Индивидуальная презентация: до 10 слайдов и 1500 слов, доказательства собственного вклада и собственная рефлексия. Не нужно выдумывать личный опыт или результаты тестов.
